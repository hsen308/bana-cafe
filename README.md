# Bana Café

[Live website](https://bana-cafe.vercel.app)

Interactive café website concept for Hamra, Beirut, combining a warm visual identity with responsive layouts and motion.

![Bana Café website preview](https://raw.githubusercontent.com/hsen308/hsen308/main/assets/projects/bana-cafe.webp)

## My role

I developed the concept, visual direction, interactions, and responsive implementation as a Novu Studios project.

## Highlights

- Custom brand palette and editorial typography
- Responsive sections for mobile and desktop
- GSAP and ScrollReveal interactions
- Custom pointer treatment on devices that support hover
- Clear location and menu-oriented content structure

## Stack

HTML · CSS · JavaScript · GSAP · ScrollReveal · Vercel

## Run locally

Open `index.html` directly or serve the folder with:

```bash
python -m http.server 8000
```
